# BhoomiNexus — Frontend (Phase 0)

Client application for the **BhoomiNexus** National Land Acquisition & Management System. Built using React 19, TypeScript, Vite, React Router, TanStack Query, React Hook Form, Zod, and Leaflet.

---

## 🚀 Running Frontend Locally

From within this `Frontend` directory:

```bash
# 1. Install dependencies
npm install

# 2. Lint check (zero errors/warnings)
npm run lint

# 3. TypeScript build verification
npm run build

# 4. Start local development server
npm run dev
```

The app will be available at **`http://localhost:5173/`**.
